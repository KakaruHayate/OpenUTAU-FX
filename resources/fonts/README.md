# Bundled fonts

The rack UI loads these three faces at start-up.  All are redistributable.

| File | Family | License |
|------|--------|---------|
| `Roboto-Regular.ttf` | Roboto | Apache License 2.0 — see `Apache-2.0.txt` |
| `Roboto-Bold.ttf` | Roboto | Apache License 2.0 — see `Apache-2.0.txt` |
| `RobotoMono-Regular.ttf` | Roboto Mono | SIL Open Font License 1.1 — see `OFL-RobotoMono.txt` |

`RobotoMono-Regular.ttf` is the `wght=400` instance of the upstream variable
font, produced with `fonttools varLib.instancer`.
